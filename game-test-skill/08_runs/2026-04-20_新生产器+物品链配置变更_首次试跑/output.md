# 测试分析输出：新生产器 + 物品链配置变更

---

## 1. 需求摘要

- 功能名称：新生产器上线 + 物品链配置变更
- 功能目标：新增一个或多个生产器，同时调整相关物品链（新增链节点、变更分支、调整来源或终点）
- 玩家入口：主盘面点击新生产器
- 归属专项：**盘面与物品链专项**（主）；订单-奖励-剧情闭环专项（次级受影响）
- 核心流程：
  1. 玩家在盘面上点击新生产器
  2. 消耗体力/次数，产出基础物品
  3. 基础物品按新/变更的物品链合成升级
  4. 最终产物用于订单提交或其他消耗
- 关键规则：
  - 生产器消耗体力或次数
  - 产出池基于权重/概率
  - 冷却/恢复机制
  - 物品链合成规则（几合几、分支、多来源）
- 状态变化：
  - 生产器解锁状态
  - 体力/次数变化
  - 盘面物品数量变化
  - 物品链节点推进
- 资源变化：
  - 消耗：体力、次数
  - 产出：基础物品、中间物品、终端物品
- 限制条件：
  - 生产器解锁条件（等级/章节/任务）
  - 体力上限与恢复
  - 次数限制与冷却
  - 盘面格数限制

---

## 2. 归属专项判断

- **主专项：盘面与物品链专项**
  - 新生产器直接影响盘面产出
  - 物品链变更直接影响合成路径和可达性
- **次级受影响专项：订单-奖励-剧情闭环专项**
  - 物品链终点可能是订单目标物
  - 链变更可能导致现有订单不可达
  - 新产出物可能影响剧情/装修推进资源
- **判断理由：** 生产器是物品来源的起点，物品链是合成的规则层，二者同时变更直接影响整个盘面底盘和下游闭环

---

## 3. 影响范围

- 涉及模块：生产器、物品链、盘面、订单、奖励
- 依赖系统：体力/次数系统、盘面网格、背包/邮件、配置系统
- 可能受影响的旧功能：
  - 依赖旧物品链的现有订单
  - 依赖旧生产器产出的合成路径
  - 旧存档中已有的中间物品映射
  - 活动物品链（如共享节点）
- 联动关注点：
  - 订单目标物的来源是否仍可达
  - 分支链/多来源链是否正确合流
  - 热更后旧存档中的旧物品是否正确映射到新链
  - 满盘时新产出物的落点处理

---

## 4. 风险分析

| 风险名称 | 风险等级 | 触发条件 | 影响范围 | 推荐测试方向 |
|---|---|---|---|---|
| 物品链断链导致订单不可达 | P0 | 新链配置错误，终点物品无合法来源路径 | 主线订单、主线推进 | 逐链验证每个终点物品的完整来源路径 |
| 旧存档物品映射错误 | P0 | 热更/配置变更后旧盘面上的物品找不到对应新链节点 | 盘面、合成、订单 | 模拟旧存档升级到新配置 |
| 生产器体力扣了但未产出 | P0 | 弱网/超时/闪退恰好在产出瞬间 | 体力、盘面、玩家资产 | 弱网、闪退恢复、体力与产出一致性校验 |
| 满盘时产出物丢失 | P0 | 盘面已满时点击生产器 | 盘面、邮件兜底、玩家资产 | 满盘、临界1格、满盘+断网 |
| 分支链/多来源链错接 | P1 | 同一物品有多个来源或分支，合成时走错路径 | 物品链、合成结果 | 验证分支逻辑正确性 |
| 生产器升级后产出池继承错误 | P1 | 升级生产器后产出池未正确切换 | 生产器、物品链 | 升级前后产出对比 |
| 活动链与主线链共享节点冲突 | P1 | 物品链变更影响到活动物品链 | 活动盘、主盘隔离 | 变更后活动链完整性验证 |
| 产出物无法拖拽/合成 | P1 | 新物品配置缺少合成规则 | 盘面交互 | 产出后立即尝试合成 |
| 冷却/恢复计时异常 | P2 | 跨天、切后台、断网后冷却状态错乱 | 生产器 | 时间边界 + 恢复态 |
| 体力/次数边界异常 | P2 | 体力恰好为0/1时点击 | 生产器 | 数值边界 |

## 5. 测试点矩阵

| 维度 | 测试点 |
|---|---|
| 主流程 | 新生产器正常解锁→点击产出→消耗体力→物品落盘→按链合成→达到终点物→提交订单 |
| 分支流程 | 分支链合成→多来源合成→容器开出→生产器升级后产出 |
| 异常流程 | 体力不足点击、次数用尽、产出时闪退、合成中断网、配置加载失败 |
| 边界条件 | 体力=0/1/满值、盘面满/临界1格、物品链首/末节点、冷却=0秒 |
| 状态切换 | 生产器锁定→解锁、冷却中→可用、升级前→升级后 |
| 重复点击/并发/重试 | 快速连点生产器、产出动画中再次点击、合成拖拽中连续操作 |
| 弱网/断线/重连/恢复 | 产出瞬间断网→重连、合成中闪退→重登、体力扣除与产出不一致检验 |
| 跨天/活动边界/热更边界 | 跨天后体力恢复+生产器状态、热更配置后旧盘面恢复、活动链共享节点 |
| 联动/回归 | 旧订单目标物可达性、旧存档兼容、星星/剧情点来源是否受影响、活动盘隔离 |

## 7. 回归建议

### 必回归
| 模块名 | 回归原因 | 重点验证内容 |
|---|---|---|
| 现有主线订单 | 物品链变更可能导致订单目标不可达 | 逐一验证当前活跃订单目标物的来源路径完整性 |
| 订单-奖励-剧情闭环 | 新链终点物品关联订单交付和奖励 | 从交付到推进的完整闭环跑通 |

| 旧存档兼容 | 配置变更后旧物品映射 | 旧版盘面物品正确映射新链 |

## 8. 本次最危险的问题

1. **物品链断链导致主线订单永久不可达** — 一旦发生玩家主线卡死，无法自行恢复
2. **旧存档中间物品映射失败** — 老玩家热更后盘面物品消失或变异，影响面极大
3. **满盘产出物丢失** — 体力已扣但物品既不在盘面也不在邮件，玩家资产不可逆丢失
4. **弱网导致体力扣了但物品未产出** — 状态不一致，玩家亏损且难以自证
5. **活动链与主线链共享节点被错改** — 主线改动无声污染活动盘，活动期间爆发

## 9. 测试执行建议

### 必须验证的闭环路径
```
新生产器解锁 → 点击产出 → 物品落盘 → 逐级合成 → 终点物品 → 提交订单 → 奖励到账 → 剧情/装修推进
```

### 必须验证的恢复路径
```
产出中闪退 → 重登 → 状态一致
合成中断网 → 重连 → 物品正确
热更后登录 → 旧物品映射正确
```

### 必须验证的边界
```
体力=0 / 体力=1 / 满盘 / 临界1格 / 跨天瞬间 / 冷却=0
```
