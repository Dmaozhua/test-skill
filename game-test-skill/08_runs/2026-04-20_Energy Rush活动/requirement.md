# Energy Rush——充能狂潮活动 需求摘要

- 来源：策划案 v1.0，负责人：落英，2026.3.24
- 原始文件：Energy Rush活动-需求.pdf

## 核心设计

- 专门售卖体力的付费活动，以不放回抽取形式，通过高价值大奖刺激付费
- 礼包共5档，付费购买后随机获得1个奖励，获得后该奖励不能再获得
- 每次购买后价格提升（走配置）
- 购买时赠送0~2个卡包（走配置）
- 活动期间只能购买1轮，全部购买完后活动结束

## 活动开启与触发

- 开启/关闭时间走服务器配置
- 开启条件：完成主线任务（策划配置）
- 弹出时机：登录弹出（优先级走配置）、没有体力时弹出（可配置是否弹）
- 玩家分层：支持WHAT分层设计

## 交互流程

1. 点击支付按钮 → 走通用支付流程
2. Step1：支付按钮置灰，转盘跑马灯动画（每个可选奖励都必须被摇到过）
3. Step2：揭示中奖结果，跑马灯停在获得奖励上
4. Step3：弹出发奖弹板（Rush Hit!），体力+卡包展示，点击任意位置领取
5. Step4：体力飞到体力槽，卡包飞到储物篮
6. Step5：界面刷新，已领取状态更新，价格刷新，新卡包奖励出现

## 奖励选取逻辑（数值设计）

- 按配置的奖励获取顺序选取
- 可配置N个批次，按批次投放
- 同批次内多个奖励按权重选择
- 示例：库1(顺序1,礼包1,100%) → 库2(顺序2,礼包2/4按80%/20%权重) → 库2(顺序4,礼包2/4按20%/80%权重) → 库3(顺序3,礼包3,100%) → 库4(顺序5,礼包5,100%)

## 边界情况

- 支付成功杀端：回到游戏弹出发奖弹板，补发确定的奖励结果
- 付费流程中活动结束：取消付费→关闭礼包；完成付费→保留资源并正常完成流程，结束后关闭活动

## UI与多语言

- info按钮：展示各档位概率，从大到小排序，已获得显示对勾在最下方
- 转盘3种状态：正常、跑马灯、已购买
- 多语言key：UI_EnergyRush_Event_title / UI_EnergyRush_EventOpen_btn / UI_EnergyRush_Reward_title
