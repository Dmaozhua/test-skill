# 《Merge+Story 类游戏测试点总表》

---

# 0. 测试对象定义

## 0.1 品类范围

适用于以下复合休闲产品：

* Merge 合成盘面
* 订单交付
* 剧情推进
* 装修/修复
* 活动运营
* 资源养成
* 体力节奏
* 商城付费

## 0.2 核心闭环

主闭环一般为：

**进入盘面 → 点击生产器 → 生成物品 → 拖拽合成 → 达成订单 → 领取奖励 → 推进剧情/装修/活动 → 解锁新内容 → 继续循环**

测试的核心目标不是只验证单点功能，而是验证整个闭环是否：

* 可进入
* 可执行
* 可完成
* 不会卡死
* 不会错发奖励
* 不会错乱状态
* 不会因活动/付费/弱网把主循环打坏
