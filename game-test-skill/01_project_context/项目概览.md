# 项目概览

## 1. 文档目的

本文件用于给 AI 建立当前游戏项目的“全局地图”。

它不负责描述单个功能细节，而是回答下面这些问题：

- 这是一个什么类型的游戏项目
- 玩家平时在这个项目里做什么
- 核心系统有哪些
- 哪些系统之间存在强联动
- 从测试视角看，哪些系统最容易出严重问题

未来 AI 在分析任何新增需求时，都应先参考本文件，建立对项目整体结构的基本认识。
