## 2. 项目基本信息

### 2.1 基础信息
- 项目类型：Merge+Story / Merge-2 + Narrative + Renovation + LiveOps
- 主要平台：移动端休闲手游（可泛化为 iOS / Android）
- 联网类型：联网 / 强联网倾向
- 当前测试阶段定位：功能测试 + 回归测试 + 运营稳定性测试并重

### 2.2 项目一句话描述
当前项目可以定义为：

**以合成盘面为核心交互，借助订单/任务驱动资源消耗与产出，再用剧情、装修和活动系统提供中长期目标的休闲手游。** fileciteturn0file5

## 3. 玩家主循环

### 3.1 日常主循环
1. 进入游戏并恢复当前盘面 / 活动状态
2. 点击生产器消耗体力或次数，产出基础物品
3. 拖拽物品、合成升级、整理盘面
4. 达成订单需求并提交订单
5. 获得金币、体力、星星、剧情点、活动积分或其他奖励
6. 消耗星星 / 剧情点推进剧情、装修、章节
7. 解锁新生产器、新物品链、新区域或新活动
8. 返回盘面进入下一轮循环 fileciteturn0file5turn0file8

### 3.2 长期成长循环
- 推进主线章节
- 解锁新区域 / 新角色 / 新剧情节点
- 解锁更高阶生产器与物品链
- 参与活动获得额外收益或稀缺资源
- 在运营活动中维持留存、回流与付费转化 fileciteturn0file5turn0file3

## 4. 核心系统总览

### 4.1 盘面系统（Board）
项目第一核心模块，负责：
- 网格盘面
- 物品占格
- 拖拽移动
- 自动吸附 / 自动落位
- 满盘判定
- 盘面保存与恢复
- 主盘 / 活动盘切换与隔离 fileciteturn0file4turn0file9

### 4.2 物品链系统（Item Chain）
项目真正复杂的规则层，负责：
- 主线合成链
- 分支链
- 多来源链
- 容器开出链
- 生产器升级链
- 活动链

高风险点是断链、错链、跳链、终点错误、来源错误。fileciteturn0file4turn0file5

### 4.3 生产器系统（Generator / Producer）
负责：
- 点击产出
- 体力或次数消耗
- 产出池 / 权重 / 概率
- 冷却与恢复
- 升级前后产出池变化

高风险点是体力扣除与产出不一致、升级继承错误、热更后产出池污染。fileciteturn0file5turn0file9

### 4.4 订单系统（Orders）
负责：
- 主线订单
- 支线订单
- 引导订单
- 活动订单（如接主闭环）
- 订单刷新 / 替换 / 放弃
- 订单提交与奖励发放

测试本质不是“能不能交”，而是“是否可达、是否可预期、是否不会卡主线”。fileciteturn0file8turn0file5

### 4.5 奖励与资源系统
负责：
- 金币 / 钻石 / 星星 / 剧情点 / 活动币 / 体力等奖励发放
- 物品型奖励、容器型奖励、邮件兜底奖励
- 背包 / 仓库 / 邮件落点与溢出处理

高风险点是多发、漏发、发错位置、状态已改但资源未到账。fileciteturn0file8turn0file9

### 4.6 剧情 / 装修 / 章节推进系统
负责：
- 剧情触发与播放
- 星星 / 剧情点消耗
- 装修步骤推进
- 区域 / 章节 / 角色 / 新功能解锁

高风险点是剧情触发错序、跳过未记状态、装修推进与资源扣除不一致、章节闭环断裂。fileciteturn0file8turn0file5

### 4.7 活动系统（LiveOps）
负责：
- 活动开启 / 关闭 / 资格判断
- 活动入口、Banner、红点、弹窗
- 独立活动盘、活动物品链、活动资源
- 活动任务、活动阶段奖励、排行、结算、清理

高风险点是活动状态错配、活动盘与主盘串数据、活动结束清理异常。fileciteturn0file3

### 4.8 热更 / 配置更新系统
负责：
- 配置热更
- 资源热更
- 活动配置切换
- 旧存档兼容
- 热更失败兜底与恢复

高风险点是半更状态、旧配置残留、旧存档对新配置映射错误。fileciteturn0file3

### 4.9 弱网 / 断网 / 重连恢复系统
负责：
- 请求重试与幂等
- 断网恢复
- 网络切换
- 切后台 / 杀进程 / 重登 / 多端恢复

高风险点是重复领奖、重复扣减、状态分叉、客户端与服务端不一致。fileciteturn0file3turn0file9

## 5. 系统联动关系

### 5.1 常见联动链路
- 生产器产出 → 盘面合成 → 订单提交 → 奖励到账 → 星星/剧情点累计 → 剧情/装修推进 → 新章节 / 新订单开放 fileciteturn0file8turn0file5
- 活动入口 → 活动盘 → 活动物品链 / 活动积分 → 阶段奖励 / 排名奖励 → 邮件或面板结算 → 活动结束清理 fileciteturn0file3
- 满盘状态 → 容器开启 / 奖励发放 / 邮件兜底 → 背包/盘面落点判断 → 后续状态刷新 fileciteturn0file4turn0file8
- 热更配置生效 → 旧盘面 / 旧订单 / 旧活动状态映射 → 恢复逻辑执行 → 客户端与配置版本一致性校验 fileciteturn0file3
- 弱网 / 断网 → 订单提交 / 奖励领取 / 活动结算 / 支付补单 → 重试与恢复 → 唯一正确状态确认 fileciteturn0file3turn0file9

### 5.2 高耦合系统说明
以下关系是一处改动极易带坏别处的高耦合链路：
- 盘面系统 ↔ 物品链 ↔ 订单系统
- 订单完成 ↔ 奖励发放 ↔ 剧情 / 装修 / 章节推进
- 活动盘 ↔ 主盘 ↔ 奖励落点 ↔ 邮件补发
- 热更配置 ↔ 旧存档 ↔ 当前盘面 / 当前订单 / 当前活动状态
- 弱网恢复 ↔ 请求幂等 ↔ 扣减 / 发放 / 状态写入唯一性 fileciteturn0file4turn0file8turn0file3

## 6. 测试视角下的高风险系统

### 6.1 盘面与物品链
风险原因：
- 这是玩法底盘，一旦断链、错链、跳链，玩家主循环直接被击穿
- 闪退 / 断网 / 满盘 / 连续拖拽都可能引发高价值事故 fileciteturn0file4

### 6.2 订单与奖励闭环
风险原因：
- 单点看都没坏，但整条链可能断在“可达性、奖励、剧情、章节推进”任一环
- 容易出现无解单、闭环断裂、奖励不足以推进等伪功能通过问题 fileciteturn0file8

### 6.3 活动系统
风险原因：
- 线上事故高发，尤其是活动开启/结束状态、活动盘隔离、活动奖励结算、活动清理
- 一旦活动数据污染主盘，修复成本极高 fileciteturn0file3

### 6.4 热更与配置切换
风险原因：
- Merge+Story 高度依赖配置，一旦热更兼容失败，会导致盘面、订单、活动、剧情整体错乱
- 旧玩家存档兼容是高风险区 fileciteturn0file3

### 6.5 弱网 / 断网 / 重连
风险原因：
- 领奖、交单、活动结算、支付补单都必须保证幂等与唯一性
- 这类问题极易演变成资源复制或玩家错账投诉 fileciteturn0file3turn0file9

## 7. 当前版本测试特别关注

AI 在当前项目中，必须优先守住以下方向：
- 主盘合成闭环是否稳定
- 订单目标是否可达
- 奖励到账是否唯一正确
- 星星 / 剧情点 / 装修 / 章节推进是否完整接上
- 活动盘与主盘是否严格隔离
- 热更后当前状态是否唯一恢复
- 弱网下是否会重复领奖、重复结算、重复发货或状态分叉 fileciteturn0file4turn0file8turn0file3
