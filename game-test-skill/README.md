# 游戏测试用例生成 AI 技能 V1

---

## 使用顺序

### 第一步：补齐项目资料

先填写以下文档：

- `01_project_context/项目概览.md`
- `01_project_context/测试策略.md`
- `03_bug_memory/历史高危问题.md`
- `05_input_templates/项目资料采集模板.md`

### 第二步：固定 AI 的输出口径

确认以下文档：

- `01_project_context/测试用例输出格式规范.md`
- `01_project_context/边界测试清单.md`
- `01_project_context/回归范围规则.md`
- `07_output_templates/测试用例输出模板.md`

### 第三步：使用 System Prompt 试跑

把以下内容一起喂给 AI：

- `06_prompts/system_prompt_v1.md`
- 新功能需求文档
- 当前项目资料
- 历史高危问题
- 输出模板

### 第四步：把试跑结果沉淀到 08_runs/

每次试跑建议建立一个目录，例如：

```
08_runs/
  2026-04-20_活动领奖功能_首次试跑/
    ├─ input.md
    ├─ output.md
    └─ review.md
```

---

## V1 输入建议

每次试跑，最少准备这些输入：

- 新功能需求文档
- 项目概览
- 测试策略
- 历史高危问题
- 风险规则/边界规则/回归规则
- 输出模板

---

## V1 输出建议

AI 输出应至少包含：

- 需求摘要
- 影响范围
- 高风险点
- 测试点矩阵
- 详细测试用例
- 回归建议
- 最危险的 3~5 个问题

---

## 当前重点风险

这套技能必须优先守住以下问题：

- 卡死 / 锁死 / 无法退出
- 资源重复获取 / 可刷
- 奖励发放异常
- 支付成功未到账 / 重复发货
- 客户端与服务端状态不一致
- 断线重连后的状态错乱
- 跨天 / 刷新 / 限次异常
- 新功能带坏旧功能

---

## 当前阶段结论

这不是一个"prompt 文件夹"，而是一套小型测试设计知识工程。

V1 先把以下三件事跑通就够了：

1. 项目资料结构化
2. 输出口径标准化
3. 用真实需求试跑并复盘
