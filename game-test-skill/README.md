---

## 1. 当前项目的测试对象定义

当前项目不是“泛合成小游戏”，而是一个典型的 **Merge+Story** 复合休闲项目：

- 以盘面合成为主战斗层
- 以订单交付为任务驱动层
- 以剧情/装修为长期推进层
- 以活动/热更/弱网稳定性为运营层

主闭环为：

**进入盘面 → 点击生产器 → 生成物品 → 拖拽合成 → 达成订单 → 领取奖励 → 推进剧情/装修/章节/活动 → 解锁新内容 → 继续循环**

因此，AI 后续生成测试用例时，必须围绕以下三层输出：

1. **盘面与物品链成立**
2. **订单-奖励-剧情闭环成立**
3. **活动 / 热更 / 弱网 / 跨日下线上运行稳定**

## 5. 当前项目最重要的高危方向

当前 skill 必须优先守住这些问题：

### P0 方向
- 主盘面合成闭环被打断
- 物品链断链 / 错链 / 跳链
- 订单不可达 / 无解单
- 奖励重复发放 / 漏发 / 发错位置
- 订单完成后闭环断裂
- 活动盘与主盘串数据
- 热更后盘面 / 订单 / 活动状态损坏
- 弱网下重复提交 / 重复领奖 / 状态分叉

### P1 方向
- 自动吸附 / 一键操作 / 分支链优先级异常
- 多订单连续完成下弹窗队列、剧情队列冲突
- 活动排行、锁榜、结算边界异常
- 跨日、跨活动、跨配置切换异常
