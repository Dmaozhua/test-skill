# 项目资料采集模板（已按真实项目改造）

## 1. 使用目的

本模板不是泛资料收集表，而是为了让后续任何一个新增功能，都能快速归位到当前 Merge+Story 项目的真实测试结构中。

填写时请优先回答：
- 这个需求改的是盘面层、闭环层，还是运营层？
- 它最可能打坏哪条链路？
- 它最需要从哪个专项进入测试？

## 9. 当前结论

本模板的作用，不是收全项目所有资料，而是让 AI 在看到一个需求时，第一时间知道：

**它属于哪个专项、最可能打坏哪条链、最该补哪些高危测试。**
