# 项目资料采集模板

## 1. 使用目的

本模板用于第一次给 AI 测试技能准备项目资料时，做最小必要收集。

原则：

- 先收最关键资料
- 不求一次整理完整个项目
- 优先收高危系统、高风险经验、高价值规则
- 先保证能试跑，再逐步补厚

## 9. 当前结论

本模板不是为了让你一次性补全全项目资料，  
而是为了先把最值钱、最影响测试质量的内容收进来。

先求能跑，再求变强。
